立体構造の可視化

GRRMプログラムの計算結果xxx.logから各ITR（イタレーション）の3次元座標を取得し、XYZ形式の構造を順に並べると、ChemCraftでコマ送り表示できます。

ユーザー定義のモチーフ構造を追加する

ユーザーが定義したモチーフ構造を追加できます。手順は以下のとおりです。

  1. 追加したい構造を選択した状態にします。moleculeでない場合は、ダミー原子Xも含めます。
  2. Edit → Add selected fragment to databaseを選び、分かりやすい名前を付けてOKを押します。

これにより、頻繁に利用する系の構造をいちいち組み立てる必要がなくなります。

参考：Working with molecular fragments（公式ヘルプ）

双極子モーメントの可視化

GRRMからGaussianを利用した計算で得られるxxx_MO.rrm（分子軌道などの情報を含むバイナリ形式のチェックポイントファイル）を、formchkでformatted checkpointファイル（.fchk）に変換します。

formchk xxx_MO.rrm xxx_MO.fchk

変換した.fchkファイルをChemCraftで開き、左下のShow dipole momentにチェックを入れると、双極子モーメントに対応するベクトルが表示されます。表示できない場合は、そもそも双極子モーメントが計算されていない可能性があります。

formchkはバイナリ形式のチェックポイントファイルをテキスト形式に変換するGaussianのユーティリティです。参考：Gaussian公式資料（PDF）。

MO（分子軌道）の可視化

双極子モーメントの表示と同様に、Gaussianのバイナリ形式のチェックポイントファイルxxx_MO.rrmを、formchkで.fchkファイルに変換しておきます。

  1. .fchkファイルをChemCraftで開き、Tools → Orbitals → Render ...をクリックします。
  2. 可視化したい軌道の番号にチェックを入れ、OKをクリックします。
  3. 左下のShow ...をクリックします。表示スタイルはstylesで変更できます。

単位格子（Unit Cell）の可視化

Tools → Crystallography tools → Build cells from Cartesian coordinatesを選ぶと、入力ウィンドウが開きます。

Enter unit cell parameters (a, b, etc.)またはEnter lattice vectorsを選び、各パラメータを入力します。後者の場合はPasteボタンでExcelのデータをそのまま貼り付けられるので、GRRMのデータなど、XYZ形式で座標を扱っている場合は便利かもしれません。

格子の枠線を表示するには、ChemCraft画面左下のCrystallography toolsからShow crystal cellを選びます。下図のような格子が表示されます。

このほかにも、セルパラメータやスーパーセルを表示する機能、あるTV（格子ベクトル）の方向にセルを伸ばして（縮めて）中身も増やす（減らす）機能など、さまざまな便利機能があります。試してみましょう。

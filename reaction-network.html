反応経路ネットワーク

GRRM の RCMC 出力をブラウザーで可視化

目次 / GRRM Tips / 反応経路ネットワーク

NODE / EDGE データを読み込む

GRRM が RCMC 計算で出力する *_NODE.cysdat と *_EDGE.cysdat を選択してください。データはこの端末内で処理します。表形式を読み取り、列の対応を確認してからネットワークを描画します。

テキストを貼り付ける

列の対応を確認してください。ヘッダーを自動判定できない場合は、列番号を選びます。

ノードにカーソルを合わせるとEQ名、エッジに合わせると対応するEaを表示します。レイアウトは連結関係を見渡すための簡易配置です。

入力形式と注意点
  • GRRM Tips に記載のとおり、NODE / EDGEデータはCytoScape用の表として出力されます。本ページはタブ・カンマ・空白区切りの表を読み込みます。
  • ファイルの書式やGRRMのバージョンによって列名が異なる場合は、列の対応を手動で選択してください。始点・終点列を特定できない場合、描画前に正しい列を指定する必要があります。
  • グラフは可視化用の簡易レイアウトで、速度論シミュレーションやネットワークの化学的解釈を行うものではありません。エッジの値を使ったフィルターは、入力にEa列がある場合のみ利用できます。

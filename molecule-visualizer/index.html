適用範囲

収束判定には可動原子の有効力を使います。一括最適化では、現在の構造と同じ元素・原子順序の各入力に同じ番号を適用し、それぞれの初期位置に固定します。MIN・AFIR-MIN・緩和スキャンでは距離・結合角・二面角の拘束と併用できます。内部座標の拘束は「計算エンジン / 経路緩和」で通常の単一構造最適化を選び、「距離・角度・二面角の拘束」から設定します。TS・IRC・経路計算・振動解析との併用は対象外です。原子固定条件はプロジェクトと結果JSONに保存されます。

描画エリアのショートカット

描画エリアをクリックしてから操作します。入力欄の編集時やダイアログ表示中には適用しません。

キー操作
Ctrl+E選択原子に直接結合した原子を追加し、選択を結合1本分広げる。
Ctrl+W選択原子から結合をたどって到達できる全原子を追加する。未選択の別分子は含めない。
Ctrl+A結合関係によらず、表示中の全原子を選択する。
Ctrl+R全原子について選択／未選択を反転する。
[ ／ ]結合した2原子をA、Bの順に選び、B側の原子団を左／右へ5°回転する。
, ／ .B側の原子団を結合方向に0.1 Å平行移動し、Aへ近づける／Aから離す。< ／ >も使用可能。
Ctrl+Z ／ Ctrl+Y座標変更を元に戻す／やり直す。

Aは先に選んだ固定側、Bは後に選んだ可動側です。A–B結合を除いてBからたどれる原子団全体が動きます。回転方向はAからBを見る向きで定めます。原子団内の形と結合表は保持します。選択順を逆にすると動かす側が入れ替わります。

[・]・,・.は長押しで反復し、1回の反復につき5°回転／0.1 Å移動します。長押し中の変更は一つの編集として扱い、Ctrl+Zで長押し前の構造へ、Redoで長押し後の構造へ戻せます。キーを離すか、別の操作を始めると、その編集を終了します。

Ctrl+E・Ctrl+Rは長押しで反復しません。E・W単独も従来どおり選択拡張／連結原子の選択に使用でき、R単独は視点をリセットします。

詳しい説明

環内の結合、動かす原子団が周期境界をまたぐ場合、結合軸が定義できない場合は座標を変更せず理由を表示します。距離を0.1 Å以下に縮める操作も行いません。Ctrl+Wをブラウザがタブ終了として優先する環境では、W単独または「連結分子を選択」を使用してください。macOSではCtrlの代わりに⌘も使用できます。

その他の操作

  • 選択：クリック／タップで原子を選択。原子上の右クリックで現在の選択へ追加し、選択済みの原子を右クリックするとその原子だけ解除します。Shift・Ctrl・⌘ または「複数選択」で追加選択。
  • 回転：選択モードで左ドラッグすると全方向へ自由回転します。ドラッグの移動量に応じて360度を超えて回し続けられます。中央付近では傾ける操作、外周では画面に対するひねり（ロール）ができます。原子の上からでも座標は変わりません。Shift＋左ドラッグは左右の移動量でロールし、カメラ位置と注視方向を保持します。
  • 表示の移動：中ボタンドラッグ。タッチでは2本指で移動・ピンチで拡大縮小。
  • 原子移動：モードを切り替えて原子をドラッグ。選択した原子を一緒に移動。Zキーで世界座標のZ方向に拘束。
  • 範囲選択：右ドラッグ、または専用モードでドラッグすると、囲んだ原子を現在の選択へ追加します。
  • 原子団の操作：Alt＋左ドラッグで平行移動、Alt＋右ドラッグで重心まわりに回転。選択中は選択原子群、未選択なら開始位置の原子・結合につながる部分が対象です。未選択で空白から開始した場合は動きません。座標の変更はUndoで復元できます。
  • キー操作（描画領域にフォーカス時）：V 選択、M 移動、B 選択原子同士の結合をすべて削除、Shift+B 選択原子同士の未接続ペアすべてに結合を生成（2原子以上。次数・種類は「結合」の設定を使用、距離による制限なし、既存結合は保持、一度の生成は10000本まで。未選択・1原子でBは結合モード）、R 全体表示、E 隣接選択、W 分子選択、Delete 削除、Ctrl / ⌘ Z 元に戻す。
  • 追加操作：ダブルクリックで分子を選択。X / Y / Zで移動方向を拘束。矢印で0.01 Å（Shiftで0.1 Å）移動、PageUp / DownでZ移動。選択原子団の回転は「測定・移動」から。
  • 周期系：セルの3ベクトル・周期方向・スーパーセルを編集できます。選択2原子の最小像距離はセル欄、通常の距離・角度は表示座標を使います。結合推定は各原子対の最小像1本です。周期像自身との結合・全近接像は未表示です。
  • 2D / 3D：Ketcherで描画・SMILES入出力。SMILES欄へ入力し「SMILES → 3D / XYZ」を押すと、直接3D座標を生成してXYZ欄に反映します。UFFで水素を追加して初期3D配座を作成します。計算化学の構造最適化を代替するものではありません。
  • 構造を整える：現在の結合を保ったまま、結合距離・角度・近接反発を概略調整します。最大500原子、H/B/C/N/O/F/Si/P/S/Cl/Br/Iに対応。周期系はセルを固定します。中止とUndoが可能です。XYZから推定した結合次数は事前に確認してください。立体配置や二面角を固定する機能はないため、大きな変形後は形状を確認してください。
  • 原子団のコピー：原子を選択し、分子ビュー上の「原子団をコピー」「原子団を貼付」を使います。分子ビューにフォーカスがあるときは Ctrl / ⌘ C・V も使えます。内部の結合・形式電荷・同位体を保持し、貼付後は選択原子をドラッグして移動できます。既存構造とは自動で結合しません。別の構造にも貼付可能です。構造列では表示中のフレームを編集します。MOL / XYZの1構造も貼付可能。ブラウザがクリップボードへのアクセスを許可しない場合、ボタンはページ内のコピーを使います。
  • データ：ファイルを画面へドロップ可能。編集内容はこのブラウザに自動保存されます。プロジェクト保存で結合種類・表示設定も保持できます。

詳しい説明

非環状の単結合回転に加え、環の2点を軸に一部分を回す連動した変形で環内単結合のねじれも変化させます。結合長・環の閉鎖を保ち、過度な結合角変化・衝突・立体反転を棄却します。芳香族・多重結合・アミドは保護し、小員環や剛直なかご構造は変形できない場合があります。配座は最大500原子、配向のみは2000原子。周期系は配向のみ対応し、原子と格子を一緒に回転します。エネルギー順の配座探索ではありません。

始点と終点を入力

原子数・元素・File-order（ファイル中の原子順序）が一致する2構造を入力してください。同元素の原子同士の対応は自動判定しません。構造数は端点を含みます。

詳しい説明

既定では入力した端点座標を保持します。周期系は両端点のセルが同一であることが必要です。衝突緩和は3N次元の局所接線に直交する方向のみです。生成後は「外部エンジン / 経路緩和」で実際のエネルギー・力を使って調整できます。生成列はエネルギー未評価のinitial guessで、最小エネルギー経路や遷移状態を保証しません。結合の生成・切断を含む経路は原子衝突と原子対応を確認してください。

生成後は描画領域下のFRAMESで順に確認できます。保存・書き出しの「全フレームXYZ」で一括保存できます。未適用の座標編集は先に適用してください。

外部エンジン / 経路緩和

計算はこのPCで起動したサービス上で実行します。座標はローカルサービスへ送信されます。接続トークンはこの画面のメモリだけに保持します。

初回のセットアップ：tblite / g-xTB / UMAを選ぶ

bridge.pyをダウンロードし、使いたいエンジンの手順で起動してください。tblite / g-xTBはPython 3.10以上、UMAはPython 3.12の専用環境を推奨します。

  • tblite：GFN2-xTB（既定）、GFN1-xTB、IPEA1-xTBを利用します。このアプリでは非周期系と固定セルの周期系に対応します。
  • g-xTB：公式のg-xTB対応実行ファイルを別途用意します。このアプリでは非周期系に対応します。tbliteのPythonパッケージは不要です。
  • UMA：fairchem-coreの学習済みモデルをローカルで実行します。この接続は非周期分子用のomolタスクです。CPU / CUDAを選べます。

通常配布版tblite 0.7.0はg-xTBに対応していません（2026年10月15日確認）。g-xTBを使いたい場合は、下の「g-xTBを使う」を選んでください。両方をインストールする必要はありません。

tbliteを使う（GFN2-xTB / GFN1-xTB / IPEA1-xTB）

Windows（Miniforgeを使用）：MiniforgeのWindows x86_64版をインストールし、スタートメニューの「Miniforge Prompt」で次を実行します。

conda create -n molecule-studio -c conda-forge --override-channels python=3.12 numpy ase psutil "tblite-python>=0.4,<1"
conda activate molecule-studio
python -c "import numpy, ase, psutil; from tblite.interface import Calculator; print('OK')"

OKが表示されたら、bridge.pyの保存先へ移動して起動します。パスは実際の保存先に置き換えてください。

cd /d "C:\Users\ユーザー名\Downloads"
python bridge.py --engine tblite --allow-origin https://h-nabata.github.io

次回以降もMiniforge Promptで conda activate molecule-studio を実行してから起動します。Windowsのpipで対応wheelが見つからない場合はソースビルドになり、Fortranコンパイラがないと「Unknown compiler(s)」で失敗します。その場合は上記のconda環境を使ってください。condaのPython APIのパッケージ名は tblite-python です。

WSL / Linux / macOS：bridge.pyの保存先で専用の仮想環境を作ります。

python3 -m venv .venv
source .venv/bin/activate
python -m pip install "numpy>=1.24,<3" "ase>=3.23,<4" "psutil>=5.9,<8"
python -m pip install --only-binary=:all: "tblite>=0.4,<1"
python bridge.py --engine tblite --allow-origin https://h-nabata.github.io

対応wheelがない場合は、ソースビルドを行わずに停止します。その場合もMiniforgeで上記のconda環境を作成できます。GFN1-xTBを使う場合は起動コマンドに --method GFN1-xTB、IPEA1-xTBなら --method IPEA1-xTB を追加します。

g-xTBを使う（公式の対応実行ファイルを指定）

公式g-xTBの配布フォルダーからOSに対応するファイルを取得し、展開してください。このアプリは xtb --gxtb --grad に対応した版を使います。通常版のxtbや、旧版の独立したgxtb実行ファイルとは区別してください。

Windows：Python 3.10以上を用意し、コマンドプロンプトで次を実行します。bridge.pyの保存先と、展開したxtb.exeがあるbinフォルダーを実際のパスに置き換えてください。付属DLLも配布時の配置を保ちます。

cd /d "C:\Users\ユーザー名\Downloads"
python -m venv .venv-gxtb
.venv-gxtb\Scripts\python.exe -m pip install "numpy>=1.24,<3" "ase>=3.23,<4" "psutil>=5.9,<8"
set "PATH=C:\path\to\g-xtb\bin;%PATH%"
"C:\path\to\g-xtb\bin\xtb.exe" --help
.venv-gxtb\Scripts\python.exe bridge.py --engine gxtb --binary "C:\path\to\g-xtb\bin\xtb.exe" --allow-origin https://h-nabata.github.io

--helpで起動でき、--gxtbと--gradが使える版であることを確認します。上の set は現在のコマンドプロンプトだけに適用されます。次回起動時もPATHを設定してから最後のコマンドを実行してください。

WSL / Linux / macOS：対応する公式バイナリを展開し、bridge.pyの保存先で次を実行します。macOSでは付属ライブラリも配置し、公式READMEの案内に従ってください。

python3 -m venv .venv-gxtb
source .venv-gxtb/bin/activate
python -m pip install "numpy>=1.24,<3" "ase>=3.23,<4" "psutil>=5.9,<8"
/absolute/path/to/xtb --help
python bridge.py --engine gxtb --binary /absolute/path/to/xtb --allow-origin https://h-nabata.github.io

tblite用の環境を既に作っている場合は、そのPython環境を再利用してg-xTB対応実行ファイルを指定することもできます。起動時の --engine gxtb で使用するエンジンが決まります。

モデル・精度・初回読み込み

モデルは uma-s-1p2p1（既定）、uma-s-1p2、uma-s-1p1、uma-m-1p1 から選べます。既定はfloat64・TF32無効。--uma-precision float32 はメモリを節約しますが、TS・微小変位の振動解析ではfloat64を推奨します。電荷と多重度はページで指定します。GFN法・SCF設定・実行ファイルの指定は不要です。エネルギーは選択したモデルのomol基準なので、tbliteやg-xTBの値と直接比較しないでください。

初回の計算で重みをダウンロードします。同じモデル・デバイスの連続計算では、重みをメモリに保持して再利用します。設定の変更時は読み直します。「計算履歴・キュー」から常駐モデルを解放できます。初回取得に時間がかかる場合は --job-timeout 7200 などで上限を延長できます。モデルのキャッシュは通常 ~/.cache/fairchem に残ります。分子の座標は外部へ送信しません。公式導入手順

LUP系（CI-String）

端点を固定し、CI開始後は最高点を基準に経路の両側を再分布します。有効力と再分布残差の両方が収束条件です。

距離・角度・二面角の拘束

原子番号は1始まりのFile-orderです。結合角 A–B–C は中央のB、二面角 A–B–C–D はB–C軸を基準に、3個または4個の番号を順に指定します。距離はÅ、結合角は1〜179度、二面角は−360〜360度です。最適化中も指定値を保ち、他の自由度を緩和します。「測定・移動」の角度変更だけでは固定されません。固定原子と矛盾する拘束や直線配置は使用できません。

IRC

現在の構造をTS候補として使用します。最大ステップ数は各方向に適用されます。入力の力が収束閾値以下であることが必要です。正逆の符号自体に反応方向の意味はありません。上の最大原子変位は端点MINに適用します。

緩和スキャン

距離・結合角・二面角から1本または2本を選び、開始値・終了値・両端を含む点数を指定します。各点では指定座標を固定し、残りの自由度を最適化します。1軸2〜100点、合計400点まで。二面角で180度をまたぐ例は170→190度（190度と−170度は同じ配座）です。最大ステップ数は各点に適用されます。同じ座標を上の拘束欄にも重複して指定しないでください。

原子IDと既存ノードのIDを保持します。分割候補の谷が極小点に収束しているかは、物理力で別途確認します。

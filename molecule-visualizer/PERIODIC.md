# 表面・バルクを計算する

## 表面の吸着と拡散を調べる

1. 表面のセルと吸着種を含むPOSCARまたは拡張XYZを開きます。セル設定で周期方向を確認します。面内だけを周期的に扱う場合は2方向を有効にします。3方向周期の反復スラブを用いる場合は真空層もセルに含めます。[入力形式](./IMPORT-FORMATS.md)
2. スラブを横から見て、分子ビューの「矩形で固定」を押し、下層をドラッグで囲みます。矩形に投影された原子が奥行き方向も含めて固定されます。複数回囲んで追加できます。「原子固定」パネルには固定数と原子番号が表示されます。「矩形で解除」またはUndoで修正できます。
3. ローカルエンジンを接続し、材料と周期方向に対応するポテンシャルを選びます。UMAでは金属触媒の表面・吸着系にOC20、酸化物表面には対応するモデルのOC22を選べます。3方向周期の入力ではOMatが初期選択されるため、真空層を含むスラブでは表面用タスクを明示的に選びます。同じ反応の全フレームを同じ重み・タスクで評価します。[エンジンの設定・タスク別の対象](./local-engine/README.md)
4. 両端の構造を用意できるときは、同じセル、原子順、固定原子の位置で反応物と生成物を指定し、DS-AFIRを実行します。境界をまたぐ短い移動には「最も近い周期像」を使います。意図した拡散が複数セルにわたる場合や等距離の像から特定の向きを選ぶ場合は、連続した入力座標で周期像を指定します。[DS-AFIRの操作](./DS-AFIR.md)
5. 結果からCI-NEBまたはCI-Stringへ初期経路を渡し、人工力を外した物理ポテンシャルで緩和します。反応物・生成物自体を緩和するかどうかと、経路全体で基板原子を固定するかどうかは別々に設定できます。あらかじめ作った構造列も直接読み込めます。
6. エネルギー極大のノードからTS最適化へ進みます。固定セルのΓ点振動解析で可動部分に有意な虚振動が1本あり、その変位が反応に対応するかを確認します。両方向のIRCと端点最適化で接続先も調べられます。Γ点は計算セルと同じ周期をもつ振動です。[振動解析とIRC](./RESEARCH.md)

実行例には、[グラフェン上のLi拡散の両端点](./examples/graphene-li-dsafir.xyz)と、[別のセルでTS最適化を始めるための固定層付きPOSCAR](./examples/graphene-li-surface-ts.vasp)があります。どちらも3方向周期・真空層付きのモデルで、tbliteのGFN2-xTBで検証しています。[数値検証](./AFIR-VALIDATION.md)

## バルク結晶を緩和する

[Si結晶の拡張XYZ](./examples/silicon-npt.xyz)を開き、セルの3方向を周期的にします。UMAで無機材料を計算する場合はOMatを選びます。「構造最適化」で原子位置のみを緩和するか、格子も緩和するか選びます。可変セルでは許すひずみ、外圧、応力の収束閾値も設定します。固定セルの計算では入力格子を全フレームで維持し、可変セルの計算では最適化履歴とともに各ステップの格子を保存します。

| 計算 | 周期系での設定 |
|---|---|
| 単点・構造最適化 | セルと周期方向を力の評価に渡します。tbliteでは非周期と3方向周期を扱い、部分周期を指定した場合は計算前に理由を表示します。 |
| AFIR・DS-AFIR・経路緩和 | 固定セル。AFIRフラグメント間の距離には周期方向の最小像を使います。経路の緩和は連続したCartesian座標で行います。 |
| TS・振動・IRC | 固定セル。完全固定した基板原子は可動部分のHessianから除きます。固定層付きの結果はその拘束下での鞍点・振動・接続先を表します。 |
| 分子動力学 | 固定した基板を含むNVE・NVT、応力に対応する3方向周期バルクでのNPT・圧力記録が可能です。[アンサンブルと熱浴](./MD.md) |
| 固定条件の入力 | POSCARの全方向固定・方向別固定を取り込みます。VASPの方向別フラグは斜方・三斜晶セルでも格子の分率座標方向を表します。方向別拘束を受理する手法と、原子単位の完全固定のみを受理する手法は画面とブリッジの両方で区別されます。 |

経路を通じて格子そのものが変わる固相転移には、可変セルの構造最適化と別に可変セル経路法が必要です。本実装のNEB・String・DS-AFIRが扱うのは、全像で格子が共通の経路です。Γ点振動解析の結果から、ブリルアンゾーン全体のフォノン分散や自由エネルギーを求めることはできません。

# Molecule Studio

GitHub Pages / Jekyll 上で動作する分子構造編集アプリ。ビルド工程や外部描画CDNは不要。

## 操作

- XYZ / MOL / SDF / プロジェクトJSONを開く、または画面にドロップ。
- 選択モードのドラッグは回転。座標のドラッグ変更は原子移動モードのみ。
- Shift / Ctrl / Cmd または複数選択チェックで追加選択。測定の順序は選択順。
- 右ドラッグまたはAltドラッグで表示を平行移動。2本指で移動・ピンチ拡大。
- 元に戻す / やり直す、座標・形式電荷の直接編集、結合編集、原子団追加。
- 編集内容はlocalStorageに保存。持ち出し・確実なバックアップにはプロジェクトJSONを保存。

## ファイル構成

- `index.html`: 日本語の操作画面。描画領域と編集タブ、入出力ダイアログ。
- `molecule-visualizer_style.css`: `.mv-app` に限定したCSS。冒頭の変数で配色を変更。
- `ui.js`: 操作、選択、入出力、履歴、自動保存。
- `renderer3dmol.js`: 既存ファイル名を維持したCanvas 2Dによる3D座標の投影描画。3Dmol.jsへの依存なし。
- `model.js`, `history.js`: 構造データとスナップショット履歴。
- `io.js`: 厳密なファイル読込と保存。
- `geometry.js`, `bonding.js`: 幾何計算と原子間距離による結合の推定。

## 仕様上の範囲

- 最大2000原子、1ファイル10MB、1構造ずつ。周期セル・TV・複数フレームは未対応。
- MOL/SDFはV2000のみ、最大999原子・999結合。形式電荷と芳香族結合次数に対応。
- 同位体、ラジカル、くさび結合など立体指定を含むMOLは、情報消失を避けて読込を拒否する。
- SDFの追加プロパティはプロジェクトとSDF書出しに保持するが、座標編集に応じた値の再計算は行わない。
- XYZは原子と座標のみ保存。配位候補・水素結合・選択的に除外した推定結合はプロジェクトJSONで保存。
- 推定結合は距離に基づく単結合または配位候補で、価数判定や構造最適化は行わない。
- 空間充填は概略表示。一部元素の表示半径は共通の代替値。
- 幾何編集は選択順の最後の原子のみを動かす。原子団全体を回す拘束最適化ではない。

## テスト

```sh
node --test molecule-visualizer/tests/*.test.cjs
```

Node標準テスト機能を使用。入出力・幾何・履歴および最小DOM/Canvasスタブによる操作統合テスト。
実ブラウザのピクセル描画やレイアウトを検証するテストではない。

変更時にはPC幅とスマートフォン幅で、表示スタイル・クリック・ドラッグ・タッチ・ダイアログ・ファイル保存を確認する。

# 分子動力学（MD）

表示中の構造に初速度を与え、接続先のエンジンが返す力で原子の運動を積分します。軌跡とともに温度とエネルギーを保存します。圧力を計算するジョブでは、各時刻の圧力・体積・格子ベクトルも確認できます。

## 画面から実行する

1. [bridge.py](./local-engine/bridge.py)を1.22.0以降に更新し、ブリッジを動かすPython環境で `python -m pip install "ase>=3.25,<4"` を実行します。使用するエンジンを指定してブリッジを再起動し、Molecule Studioから接続します。
2. 入力構造を開き、「計算手法を選ぶ」から「分子動力学（MD）」を選びます。構造列から始める場合は、出発点にしたいフレームを表示します。
3. アンサンブルを選びます。画面の初期設定はNVT、熱浴はNosé–Hoover鎖です。NVEでは初速度、NVTでは温度と熱浴、NPTでは温度・熱浴と外圧を設定できます。
4. 時間刻み、積分ステップ数、保存間隔を確認して実行します。たとえば0.5 fsで100ステップなら50 fsの計算です。10ステップごとに保存すると、初期構造を含めて11フレームになります。
5. 「軌跡を再生」で運動を確認し、「最終構造を適用」で最終時刻の構造とセルを編集画面に取り込みます。「構造列を保存・抽出」から複数フレームXYZ、計算結果から熱力学量・最終速度を含むJSONを書き出せます。

| アンサンブル | 設定する量 | 積分・サンプリング |
|---|---|---|
| NVE | 初速度または初期温度 | セルを固定し、velocity Verletで時間発展を追います。全エネルギーのドリフトから刻み幅を点検できます。 |
| NVT | 温度、熱浴 | セルを固定し、熱浴とエネルギーを交換します。 |
| NPT | 温度、熱浴、外圧（bar） | セルの形と角度を保ち、等方的な体積変更をモンテカルロ法で試行します。 |

| 接続先 | ポテンシャルと周期条件 |
|---|---|
| g-xTB、tblite | 指定した電子状態計算のエネルギーと力を用います。g-xTB接続は孤立分子用です。tbliteでは3方向に周期的なセルでNPTと圧力記録を利用できます。 |
| UMA、llmlip.rs | UMAの直接接続は分子用のomol設定です。llmlip.rsでは登録モデル・選択ヘッドが周期系と応力に対応すればNPTと圧力記録を利用できます。セルの大きさはモデルのカットオフ条件に合わせます。 |
| RDKit | MMFF94、MMFF94s、UFFから選択します。非周期の閉殻分子を対象に、水素を含む全原子、共有結合の次数、各原子の形式電荷を用います。 |

## 熱浴の選び方

| 熱浴 | 運動への作用 | 設定 |
|---|---|---|
| Nosé–Hoover鎖（既定） | 3段の鎖を持つ決定論的な熱浴です。初期座標・速度と条件をそろえると同じ運動を再現できます。 | 熱浴の緩和時間（既定100 fs） |
| Bussi（確率的速度リスケーリング） | 全原子の熱運動の速度に共通の確率的な倍率を掛けます。カノニカル分布に従う運動エネルギーの揺らぎを保ちながら温度を調節できます。 | 熱浴の緩和時間（既定100 fs）、乱数シード |
| Langevin（BAOAB） | 各原子に摩擦と揺動力を作用させます。摩擦係数を大きくするほど速度は速く緩和します。 | 摩擦係数（既定10 ps⁻¹）、乱数シード |

原子の運動を時間の関数として比較するときは、熱浴の種類と結合の強さを記録してください。熱浴は速度の相関にも影響します。静止した平衡構造を加熱する場合、Nosé–Hoover鎖では初速度を温度分布から生成します。力も速度もゼロの状態では、この決定論的な熱浴は運動を開始できません。[Nosé–Hoover鎖の原論文](https://doi.org/10.1063/1.463940)・[Bussi熱浴の原論文](https://doi.org/10.1063/1.2408420)

## 周期系の圧力とシリコンの入力例

[ダイヤモンド型シリコンの基本セル（拡張XYZ）](./examples/silicon-npt.xyz)を開き、tbliteのGFN2-xTBに接続してください。NPTを選び、たとえば300 K、1 bar、0.5 fs、500ステップで実行すると、既定の間隔では25ステップごとに計20回の体積変更を試行します。採択された試行でのみセルが変わります。この短い例では体積変化・保存・再生の操作を確認できます。

体積を変更するときは全原子の分率座標を保ってセルを等方的に拡大・縮小します。対数体積の変化量を一様に選び、エネルギー差、外圧の仕事、体積のヤコビアンから採否を決めます。セルの変化幅は既定で対数体積の±0.01です。この圧力浴は等温等圧分布をサンプリングするためのもので、セルが伸縮する物理的な時間応答は算出しません。

瞬間圧力は圧縮を正とし、運動エネルギーと接続先の応力テンソルから求めます。瞬間値は外圧の周囲で揺らぎ、特に少数原子のセルでは大きく変動します。NPTで重心並進を除いた場合は、除いた3つの運動量自由度について目標温度から求めた圧力寄与を加えます。体積を固定した系の圧力を知りたいときは、NVEまたはNVTで「圧力を記録」を選びます。この場合は実際の速度と応力から固定セルでの圧力を計算します。

### 古典力場を使う

ブリッジを動かすPython環境にRDKitを追加します。公開ページからの接続を許可して起動する例です。

```bash
python -m pip install 'ase>=3.25,<4' 'psutil>=5.9,<8' rdkit
python bridge.py --engine rdkit --allow-origin https://h-nabata.github.io
```

[二重結合と水素を明示した1,3-ブタジエンのSDF](./examples/butadiene-md.sdf)をそのまま使えます。XYZを使う場合は、距離から推定した結合を結合編集で確認してください。たとえばブタジエンの共役二重結合を単結合として渡すと、原子型や水素数が変わります。力場パラメータを割り当てられない場合は計算を停止します。RDKitの3力場は運動中も最初の結合表を用いるため、分子の振動や配座変化に利用できます。環化や開環には、結合の組み替えを記述できる電子状態計算か、対象反応を記述できる学習済みポテンシャルを選びます。

## 積分法と保存条件

初速度をMaxwell–Boltzmann分布から生成すると、初期の運動温度も指定値の周りで変動します。速度を直接入力する場合は入力構造と同じ原子順にÅ/fsで指定します。「重心の並進運動を除く」を選ぶと初速度から質量加重平均速度を引き、熱浴は相対運動に作用します。単原子では並進3自由度を使用します。

全エネルギーは同じ時刻のポテンシャルエネルギーと運動エネルギーの和です。NVEの数値精度は、初期座標・初速度と総時間をそろえ、時間刻みを半分にした軌跡と比較できます。NVT・NPTでは熱浴との間でエネルギーを交換し、NPTでは外圧の仕事も伴います。

1ジョブは1〜500原子、最大100,000ステップです。保存は最大1,000フレームかつ延べ100,000原子までで、初期と最終のフレームを含みます。保存間隔を広げても積分の刻みは変わりません。周期系の座標はセル境界で折り返さずに記録します。NPTの軌跡ではフレームごとにセルを保存します。中止・失敗時は取得済みのフレームまでが途中結果です。履歴から同じ条件で初めから再実行できます。

## 同じブタジエン構造から開環方向と閉環方向を調べる

[同旋型CI-NEBの最高点（XYZ）](./examples/butadiene-conrotatory-ts.xyz)を開き、g-xTBに接続します。この構造では投影前の最大力が0.034 eV/Å、有限差分振動解析で有意な虚振動が1本（809i cm⁻¹）でした。NVE、0.25 fs、160ステップ、保存間隔1、重心並進の除去をオフに設定します。「初期速度の指定」で「原子ごとに入力」を選び、下の10行を貼り付けます。各行が原子1個の速度で、単位はÅ/fsです。

```text
-0.0057735856 -0.0025849581  0.0000471711
-0.0011474032  0.0023074511 -0.0007263586
 0.0011474032  0.0023074511  0.0007263586
 0.0057735856 -0.0025849581 -0.0000471711
 0.0099743017  0.0061437517 -0.0071584414
-0.0102762981 -0.0053444350  0.0046239236
 0.0015948910  0.0025073665 -0.0064868185
-0.0015948910  0.0025073665  0.0064868185
-0.0099743017  0.0061437517  0.0071584414
 0.0102762981 -0.0053444350 -0.0046239236
```

上記の速度は虚振動方向に合計0.100 eVの運動エネルギーを与えます。全成分の符号を反転して同じ初期構造からもう一度実行すると、閉環方向の運動を比較できます。実測したC1–C4距離は、始点で2.10342 Å、20 fs後はそれぞれ2.64108 Åと1.50435 Åでした。この2本は特定の運動を励起した軌跡で、生成物比や熱反応速度の推定には使用していません。[実測・再計算手順](./AFIR-VALIDATION.md)

無置換ブタジエンの逆旋側には、多参照計算で逆旋と同旋に対応する2本の虚振動が報告されています。静的計算でその二次鞍点を調べることと、初速度を与えた系の時間発展をMDで調べることは、別の問いです。今回の同旋MDは既知の一次鞍点を利用した動作検証です。[Mirzanejad・Muechler, ChemPhysChem (2025)](https://doi.org/10.1002/cphc.202400786)

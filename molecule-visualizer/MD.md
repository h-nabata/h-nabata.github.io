# 分子動力学（MD）

表示中の構造に初速度を与え、接続先のエンジンが返す力で原子の運動を積分します。各時刻の構造、温度、ポテンシャルエネルギー、運動エネルギー、全エネルギーを確認できます。bridge.py 1.21.0以降を使用します。

## 画面から実行する

1. [bridge.py](./local-engine/bridge.py)を更新し、使いたいエンジンで起動します。Molecule Studioで構造を開き、「計算手法を選ぶ」から「分子動力学（MD）」を選びます。構造列から始める場合は、出発点にしたいフレームを表示します。
2. ローカルのブリッジに接続し、アンサンブル、時間刻み、積分ステップ数、保存間隔を入力します。たとえば0.5 fsで100ステップなら50 fsの計算です。10ステップごとに保存すると、初期構造を含めて11フレームになります。
3. 温度から初速度を生成するか、「初期速度・乱数」で原子ごとに速度を指定して実行します。原子の順序は入力構造と同じです。NVEの温度指定は初速度の生成に使います。NVTの場合は指定温度が熱浴の温度になります。
4. 計算後、「軌跡を再生」で分子の運動を確認します。最終構造だけを編集する場合は「最終構造を適用」を選びます。「構造列を保存・抽出」から複数フレームXYZ、結果の保存ボタンから熱力学量・最終速度を含むJSONを書き出せます。

| 接続先 | ポテンシャルと入力 |
|---|---|
| g-xTB、tblite | 選んだ電子状態計算のエネルギーと力。g-xTBは非周期、tbliteは固定セルの周期系にも対応します。 |
| UMA、llmlip.rs | 接続先に登録されたモデルのエネルギーと力。UMAは既存の分子用omol設定、llmlip.rsはモデルが対応する元素・周期条件を使います。 |
| RDKit | MMFF94、MMFF94s、UFFから選択します。非周期の閉殻分子を対象に、水素を含む全原子、共有結合の次数、各原子の形式電荷を用います。 |

### 古典力場を使う

ブリッジを動かすPython環境にRDKitを追加します。公開ページからの接続を許可して起動する例です。

```bash
python -m pip install 'ase>=3.23,<4' 'psutil>=5.9,<8' rdkit
python bridge.py --engine rdkit --allow-origin https://h-nabata.github.io
```

[二重結合と水素を明示した1,3-ブタジエンのSDF](./examples/butadiene-md.sdf)をそのまま使えます。XYZを使う場合は、距離から推定した結合を結合編集で確認してください。たとえばブタジエンの共役二重結合を単結合として渡すと、原子型や水素数が変わります。力場パラメータを割り当てられない場合は計算を停止します。RDKitの3力場は運動中も最初の結合表を用いるため、分子の振動や配座変化に利用できます。環化や開環には、結合の組み替えを記述できる電子状態計算か、対象反応を記述できる学習済みポテンシャルを選びます。

## 積分法と保存条件

NVEにはvelocity Verlet、NVTにはLangevinのBAOAB積分を用います。乱数を使うときはシードを記録します。初速度をMaxwell–Boltzmann分布から生成した場合、個々の短い軌跡の初期温度と瞬間温度は指定値の周りで変動します。速度を直接入力した場合は、入力値の大きさを保ちます。「重心の並進運動を除く」を選ぶと初期速度から質量加重平均速度を引き、Langevin熱浴も相対運動に作用します。単原子では並進3自由度を使用します。

全エネルギーは同じ時刻のポテンシャルエネルギーと運動エネルギーの和です。NVEの数値精度を点検するには、初期座標・初速度と総時間をそろえ、時間刻みを半分にして全エネルギーのずれを比較します。NVTでは熱浴とのエネルギー交換を伴います。

1ジョブは1〜500原子、最大100,000ステップです。保存は最大1,000フレームかつ延べ100,000原子までで、初期と最終のフレームを含みます。保存間隔を広げても積分の刻みは変わりません。周期系の軌跡には固定したセルと連続なCartesian座標を記録します。中止・失敗時は取得済みのフレームまでが途中結果です。履歴から同じ条件で初めから再実行できます。

## 同じブタジエン構造から開環方向と閉環方向を調べる

[同旋型CI-NEBの最高点（XYZ）](./examples/butadiene-conrotatory-ts.xyz)を開き、g-xTBに接続します。この構造では投影前の最大力が0.034 eV/Å、有限差分振動解析で有意な虚振動が1本（809i cm⁻¹）でした。NVE、0.25 fs、160ステップ、保存間隔1、重心並進の除去をオフに設定します。「初期速度の指定」で「原子ごとに入力」を選び、下の10行を貼り付けます。各行が原子1個の速度で、単位はÅ/fsです。

```text
-0.0057735856 -0.0025849581  0.0000471711
-0.0011474032  0.0023074511 -0.0007263586
 0.0011474032  0.0023074511  0.0007263586
 0.0057735856 -0.0025849581 -0.0000471711
 0.0099743017  0.0061437517 -0.0071584414
-0.0102762981 -0.0053444350  0.0046239236
 0.0015948910  0.0025073665 -0.0064868185
-0.0015948910  0.0025073665  0.0064868185
-0.0099743017  0.0061437517  0.0071584414
 0.0102762981 -0.0053444350 -0.0046239236
```

上記の速度は虚振動方向に合計0.100 eVの運動エネルギーを与えます。全成分の符号を反転して同じ初期構造からもう一度実行すると、閉環方向の運動を比較できます。実測したC1–C4距離は、始点で2.10342 Å、20 fs後はそれぞれ2.64108 Åと1.50435 Åでした。この2本は特定の運動を励起した軌跡で、生成物比や熱反応速度の推定には使用していません。[実測・再計算手順](./AFIR-VALIDATION.md)

無置換ブタジエンの逆旋側には、多参照計算で逆旋と同旋に対応する2本の虚振動が報告されています。静的計算でその二次鞍点を調べることと、初速度を与えた系の時間発展をMDで調べることは、別の問いです。今回の同旋MDは既知の一次鞍点を利用した動作検証です。[Mirzanejad・Muechler, ChemPhysChem (2025)](https://doi.org/10.1002/cphc.202400786)

# 反応経路・計算管理・解析

計算はこのPCのbridge.pyへ明示的に送信します。入力と結果を外部へ送信せず、計算条件と原子IDを保持します。新しい画面を使うときは配布中のbridge.pyに差し替えて再起動・再接続してください。追加パッケージはIRC・TS用の `python -m pip install "sella>=2.6,<3"` です。

## IRC

「IRC」から現在表示中のTS候補を入力します。正方向・逆方向・両方向を選び、質量重み付きステップ幅をÅ√amuで指定します。既定は0.1 Å√amu。最大ステップ数は各方向に適用し、任意の端点MINにも同じ上限を別途適用します。

SellaのIRCを使用します。初期構造の最大物理力が指定閾値以下で、初期近似Hessianに負曲率があることを確認します。これは完全な振動解析による一次鞍点の確認とは異なります。端点MINの構造は `framePhases=endpoint_minimization` としてIRCから区別します。両方向の結果は逆方向端点→TS→正方向端点の順に並べ、TSを重複させません。端点の力が収束しても、IRC自体が上限で停止した場合は未収束のままです。端点の化学種同定・振動解析は自動判定しません。非周期分子・200原子以下が対象で、拘束・人工力を同時に加えません。

## 計算履歴・キュー・モデル常駐

「計算履歴 / キュー」で待機中・実行中・完了・中止・失敗・中断した計算を表示します。入力条件の復元、結果の読み込み、JSON保存、再開、アーカイブ、個別削除ができます。別の計算中も条件を用意してキューへ追加でき、登録順に1件ずつ実行します。待機上限は100件。アーカイブは一覧から隠す操作で、ファイルの削除とは異なります。

履歴は既定で次へ保存します。画面と起動時の `History:` に実際の保存先を表示します。

| OS | 既定の保存先 |
|---|---|
| Windows | `%LOCALAPPDATA%\molecule-studio\jobs` |
| Linux / WSL | `$XDG_DATA_HOME/molecule-studio/jobs`、未設定なら `~/.local/share/molecule-studio/jobs` |
| macOS | `~/Library/Application Support/molecule-studio/jobs` |

`--history-dir /path/to/jobs` で変更し、`--no-history` でディスク保存を無効にできます。チェックサム付きJSONを一時ファイル経由で置き換え、評価済みチェックポイントを概ね1秒ごと、終了状態を即時保存します。強制終了では直近の未保存分が失われることがあります。次回起動では未完了レコードを「中断」とし、勝手に再実行しません。保存失敗は画面へ表示します。トークン・モデルの認証情報は保存しません。

MIN・AFIR・TS・CI-NEBの再開は、保存済みの最終評価構造から同じ条件で**新しい最適化**を始めます。速度、FIRE状態、近似Hessian、CI開始カウントは初期化します。元の計算は親ジョブとして残し、結果を上書きしません。スキャンは保存した格子点を保持して未完了点から続行します。IRCと振動解析は元の入力から再実行します。エンジン・モデル・重み・パッケージ等の識別情報が変わった場合は再開を拒否し、結果を新しい入力として取り込む操作を使います。

UMA／AnySolvはモデル・デバイス・精度の組合せが同じならプロセスと重みを次のジョブへ引き継ぎます。元素・電荷・多重度・溶媒・ASE計算状態は更新します。各モデルのGPU選択は独立です。モデル条件変更、失敗・中止、サービス終了で解放し、画面からの解放と `--no-resident-models` にも対応します。g-xTBの各評価ファイル、ASE振動解析の差分キャッシュ等はジョブ用一時ディレクトリに作り、ジョブ終了時に削除します。保存済みJSONとモデルのダウンロードキャッシュは残ります。

## 距離・角度・二面角の拘束と緩和スキャン

計算設定の「内部座標の拘束」で種類、File-orderの原子番号、値を指定します。距離はÅ、角度・二面角は度です。MIN・AFIR-MIN・スキャンに適用し、原子固定とも併用できます。HTTPでは0始まりインデックス、画面では1始まり番号を使います。

ASEの解析的内部座標微分からJacobianを作り、固定原子の自由度と一緒にSVDで力を射影します。座標はNewton反復で同時拘束へ戻し、固定原子の位置を保持します。入力が指定値と異なる場合は最初に拘束面へ射影し、元構造・射影後構造・最大変位を `constraintProjection` に残します。特異な角度、矛盾した拘束、射影失敗、原子衝突はエラーにし、拘束を黙って解除しません。収束は拘束後の有効力で判定します。物理力とAFIR人工力はそれぞれ別に保存します。

スキャンは1本または2本の座標軸に対して等間隔の目標値を作り、各点で残りの自由度を最適化します。1軸2〜100点、全体400点以下。初期構造には直近の収束点を使用し、未収束点で停止するか続行するかを選べます。各点の目標値・実際の値・収束・エネルギーを保存します。点ごとの最大ステップ数は共通設定を使用します。2次元結果のフレーム順は走査順であり、そのまま一本の最小エネルギー経路を意味しません。

## CI-NEBの自動ノード追加・経路分割

自動追加は任意でオンにします。指定間隔または仮の力収束時に隣接ノードの原子RMS変位と物理エネルギー差を調べ、閾値を超える区間へCartesian中点を追加します。回転・並進の整列は行いません。最大100ノード、既存ノードのIDと端点座標を保持し、追加後はFIRE状態を初期化します。中点に0.1 Å未満の衝突がある区間は追加を見送り、結果へ記録します。この実装は独自の間隔判定であり、ASE AutoNEBそのものではありません。

力の収束と経路の離散化条件を区別します。ノード上限や衝突によって未解決の区間が残った場合は `adaptiveStatus` に記録します。途中ノードの計算が失敗した場合には最後の完全に評価済みの経路を保持します。ライブ表示では追加後も選択したノードIDを追跡します。

経路分割はエネルギーの移動平均、谷の突出度、最小間隔から境界候補を作り、元データでも極小となる構造を選びます。分割結果から各区間をCI-NEBへ渡せます。境界候補の物理力が未収束なら端点最適化が必要と表示します。平滑化は候補の検出にだけ使用し、構造と実エネルギーを変更しません。各区間のCIは最高内部ノード1個であり、複数のTSが自動的に検証済みになるわけではありません。

## 収束診断と成分

診断パネルにステップごとのエネルギー、最大力、原子ごとの力ノルムのRMS、最大原子変位、エネルギー変化を表示します。AFIRでは物理・人工・合計、AnySolvではUMA・溶媒補正、CI-NEBでは接線除去・ばね・登坂補正・拘束補正と有効力を区別します。ベクトル成分の和と、各成分の最大ノルムの和は同じではありません。UMA＋溶媒補正は物理力の内訳であり、物理力へ重ねて二重加算しません。IRCの表示力は物理力で、IRCの更新方向とは異なります。データのない成分をゼロとして補いません。

## 熱化学量

MIN・TS・振動解析の「熱化学量・自由エネルギー」をオンにすると、振動解析後にZPE・H・S・Gを計算します。既定オフ。温度、圧力、回転対称数、構造種別、気体／1 M標準状態を指定します。

質量規格化されたASEモードからHessianを再構成し、非線形分子6、直線分子5、単原子3の剛体運動を射影除去します。単に周波数の小さい順に削除しません。入力の力が収束し、極小なら有意な虚振動0本、TSなら1本であることを要求します。残る微小虚振動も自動的に実振動へ変換しません。低振動数処理は調和近似または振動エントロピーだけに周波数の下限を設ける方式で、ZPEとHは元の実振動を使います。1 M換算は `kBT ln(1000 RT/P)` をGへ加えます。

AnySolv使用時はUMA＋溶媒補正を基準値として分子RRHO補正を加えた推定です。溶液中の全自由エネルギーを厳密に求めるものではなく、標準状態の整合性が必要です。熱化学計算が成立しなくても、既に計算した構造と振動解析結果は保持します。

## 重ね合わせ・重複判定

構造列または一括最適化の結果を選び、全原子／水素以外を対象に、並進と正回転による最小RMSDで重ね合わせます。鏡映は許さず、安定した原子IDの対応を保ちます。原子対応が確定できない場合に元素だけで推測して並べ替えません。周期系の最小像比較は対象外です。

表示の重ね合わせは元の座標データを変更しません。閾値以下の構造を代表構造に対してまとめ、同じ計算条件で比較できる場合のみ最低エネルギーの構造を代表に選びます。代表構造をフレームやXYZへ出力できます。RMSDによる幾何学的な重複判定であり、化学種同一性や反応経路の接続を保証しません。

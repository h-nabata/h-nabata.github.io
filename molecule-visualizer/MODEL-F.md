# 2状態のポテンシャル面（ModelF / AMF）

bridge.py **1.14.0以降**で、異なる2つのスピン多重度のエネルギーと力を合成し、下側または上側のモデル面で構造最適化・経路緩和を実行できます。[GRRM Tipsの「ModelFについて（Opt=Xでない場合）」](https://h-nabata.github.io/grrm-tips.html#h.r1lr9osty2d0)に記載されたAvoiding Model Function（AMF）を使用します。GRRM自体を実行する機能ではありません。

## 設定と使い方

1. 最新の[bridge.py](./local-engine/bridge.py)を保存し、ローカルサービスを再起動して接続し直します。起動コマンド・依存パッケージは従来どおりです。
2. 計算設定の「2状態のポテンシャル面（ModelF / AMF）」を開き、有効にします。
3. 通常の「スピン多重度」を状態1、「状態2のスピン多重度」を状態2として指定します。一重項・三重項の組合せは **1と3** です。AFIRではAFIRパネル側の多重度が状態1になります。
4. 追跡面を「下側」または「上側」、平滑化パラメータαをkJ/molで指定します。既定値は下側・30 kJ/molです。
5. 通常と同じ操作でMIN、AFIR、CI-NEB、LUP系などを実行します。両端点を含む構造列の経路緩和では、全ノードに同じ面・αを使用します。

αの変更や上下の面の切替は新しい計算として実行します。保存履歴からの「再開」は元の条件を維持します。条件プリセット・結果JSON・プロジェクトにもModelF設定が残ります。

## エネルギー・力の定義

同じ原子配置Qで2状態を評価します。電荷・原子順序・計算手法・溶媒条件は共通です。

$$\Delta=E_1-E_2,\qquad U=\frac{\alpha}{2}\exp[-(\Delta/\alpha)^2]$$

$$E_\pm=\frac{E_1+E_2}{2}\pm\frac{1}{2}\sqrt{\Delta^2+4U^2}$$

下側はE−、上側はE+です。αを内部でeVへ換算してから合成します（1 eV = 96.48533212331002 kJ/mol）。交差点E₁=E₂では **U=α/2、上下のエネルギー差はα** です。αは一定のカップリングUそのものではありません。エネルギー差が大きくなるとUは減衰します。

力にはUの座標依存性も含めます。t=Δ/α、R=√(Δ²+4U²)とすると、

$$D=\frac{\Delta}{R}(1-2e^{-2t^2}),\quad w_1=\frac{1\pm D}{2},\quad w_2=1-w_1,\quad \mathbf F_\pm=w_1\mathbf F_1+w_2\mathbf F_2.$$

符号は選択面と同じです。このwはエネルギー微分による**力の係数**であり、状態の存在確率ではありません。周期セルの応力にも同じ係数を適用します。2×2行列の対角化や、この合成のための力の数値差分は不要です。TS・振動解析の差分処理は従来のアルゴリズムに従います。

α=0はmin(E₁,E₂)またはmax(E₁,E₂)を使用します。交差点近傍（|Δ|≤10⁻¹² eV）で両状態の力またはセル応力が異なる場合は微分が一意に決まらないため停止します。滑らかな経路を追跡する場合は正のαを使用してください。

## 対応する計算

| 項目 | 動作 |
|---|---|
| エネルギー・力評価、MIN、一括MIN | 選択したAMF面のエネルギーと力を使用 |
| AFIR | AMF面のエネルギー・力に人工項を加算。モデル面と人工項を別々に保存 |
| NEB、CI-NEB、LUP系、直交緩和 | 全ノードを同じ選択面で評価。固定端点を維持 |
| 内部座標拘束・緩和スキャン、原子・原子団拘束 | 各機能の既存の対応範囲で使用可能 |
| Sella TS、振動解析、IRC | 選択面を共通の計算器として使用。非周期系・既存の原子数上限などは継続 |
| 周期系・セル最適化 | tbliteで対応。固定セル、相似伸縮、角度固定、c軸など既存モードを使用 |
| UMA + AnySolv | 各状態でUMAと溶媒補正を加えた後、その2つのエネルギーと力をAMFで合成 |
| 熱化学補正 | 合成面の電子縮退度が一意でないため未対応。振動解析のみ使用可能 |

## 結果の確認・保存

結果欄にE₁、E₂、E−、E+の4系列を同じ基準で表示します。縦軸は選択面の最低エネルギーを0としたkJ/mol、横軸は構造番号です。MINでは最適化履歴、経路計算では最終経路を表示します。構造番号のスライダーで絶対エネルギー（eV）、Δ、Uを確認できます。分子と選択面の通常のエネルギープロファイルも従来どおり使用できます。

「両状態・上下両面のCSVを保存」は全点を保存します。大量の点のグラフは区間の極値を残して間引きますが、保存値は間引きません。結果JSONの`modelF`に設定、`surfaceComponents`に`state1EV`、`state2EV`、`gapEV`、`couplingEV`、`lowerEV`、`upperEV`、`weight1`、`weight2`を保存します。AnySolv併用時は各状態のUMA・溶媒成分も保存します。XYZのコメントにも追跡面・α・両状態のエネルギーを記録します。条件を復元する用途には結果JSON・履歴またはプロジェクトを使用してください。

計算途中の中止・失敗では、**両状態の評価が完了した構造だけ**を残します。片方の状態が収束しない場合に、もう片方だけの面へ自動的に切り替えることはありません。

## 計算コストと適用範囲

同一座標で2状態を評価するので、物理計算の回数は通常の単一面より増えます。合成処理はスカラー式と力の加重和です。長い経路の成分キャッシュは2048組に制限し、固定端点のキャッシュ再利用を維持します。CPU計算では状態別のSCCキャッシュ、UMAでは共有モデル重みと状態別の座標キャッシュを使用します。AnySolvの常駐プロセスも共有し、多重度を切り替えます。UMA/AnySolvのモデル重みを2状態分複製しません。実行時間が必ず2倍になるわけではなく、各状態の収束性に依存します。結果の`performance.stateEngineCalls`で状態別の評価回数を確認できます。

この実装は**同じ接続エンジンで異なる多重度を計算する方式**です。同じ多重度内の励起根の指定、異なるエンジン・手法間の混成、波動関数による状態追跡は未対応です。スピン軌道相互作用を計算する機能、MECP（Opt=X）探索、非断熱動力学、項間交差の確率・速度の評価でもありません。

一重項から三重項ビラジカルへ至る経路の候補を、このモデル面で検討できます。ただし、開殻一重項・多配置性・解離極限の妥当性は各電子状態計算法に依存します。多重度1を指定するだけでbroken-symmetry解や多配置波動関数を得られるわけではありません。得られた経路・障壁はαへの依存性と各状態の計算結果を併せて評価してください。
